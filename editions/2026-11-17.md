## 1. Windows 11 Tracks Developer Tool and Coding Agent Usage

Windows 11 uses a system DLL called MissionControlAggregator.dll to track the usage of specific coding agents and developer tools like python.exe, dotnet.exe, gcc.exe, and code.exe. Unless users opt out of optional diagnostic data, this usage information is uploaded to Microsoft.

**Why it matters:** Your local development tool usage and AI coding assistant activity may be transmitted to Microsoft unless you explicitly opt out of optional diagnostics.
